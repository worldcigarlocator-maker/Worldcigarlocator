Política de Privacidade

Última atualização: fevereiro de 2026

World Cigar Locator (“WCL”, “nós”, “nosso” ou “nos”) respeita sua privacidade e está comprometido em proteger dados pessoais de acordo com o Regulamento Geral de Proteção de Dados da União Europeia (GDPR).

Esta política explica quais dados coletamos, como os utilizamos e quais são os seus direitos.

1. Controlador de Dados

World Cigar Locator é o controlador dos dados pessoais processados através deste site. Para questões relacionadas à privacidade, entre em contato conosco através do link Contact / Support.

2. Quais Dados Coletamos

a) Informações Fornecidas por Você

Podemos coletar:

  • Nome (se fornecido)
  • Endereço de e-mail
  • Mensagens enviadas via Contact / Support
  • Relatórios enviados via Report a Listing

O fornecimento dessas informações é voluntário.

b) Informações Coletadas Automaticamente

Quando você visita o site, podemos coletar:

  • Endereço IP
  • Tipo de navegador
  • Informações do dispositivo
  • Páginas visitadas
  • Dados de interação

Esses dados são utilizados para segurança, análises e melhoria da plataforma.

3. Base Legal para o Tratamento (GDPR)

Processamos dados pessoais com base em uma ou mais das seguintes bases legais:

  • Interesse legítimo (operar e melhorar a plataforma)
  • Consentimento (quando aplicável)
  • Cumprimento de obrigações legais

4. Como Utilizamos os Dados Pessoais

Utilizamos os dados para:

  • Responder a consultas
  • Revisar e moderar relatórios enviados
  • Melhorar funcionalidades e desempenho
  • Monitorar e prevenir abusos
  • Manter análises operacionais

Não vendemos dados pessoais.

5. Processamento de Dados & Infraestrutura

Para operar o World Cigar Locator, utilizamos provedores terceirizados confiáveis para hospedagem em nuvem, infraestrutura de banco de dados, serviços backend e análises.

Isso inclui plataformas modernas baseadas em nuvem (como Supabase) utilizadas para armazenar e processar dados operacionais com segurança.

Esses provedores atuam como processadores de dados e processam dados em nosso nome sob salvaguardas apropriadas, em conformidade com os requisitos do GDPR.

6. Retenção de Dados

Os dados pessoais são mantidos apenas pelo tempo necessário para cumprir os propósitos descritos nesta política ou conforme exigido por lei.

Mensagens de suporte e relatórios podem ser armazenados para fins operacionais, de auditoria e controle de qualidade.

7. Transferências Internacionais de Dados

Caso dados pessoais sejam processados fora do Espaço Econômico Europeu (EEE), salvaguardas apropriadas serão implementadas em conformidade com os requisitos do GDPR.

8. Seus Direitos sob o GDPR

Se você estiver localizado na UE/EEE, possui o direito de:

  • Acessar seus dados pessoais
  • Solicitar correção
  • Solicitar exclusão (“direito ao esquecimento”)
  • Restringir o processamento
  • Opor-se ao processamento
  • Solicitar portabilidade de dados
  • Registrar reclamação junto à autoridade supervisora local

Para exercer seus direitos, entre em contato conosco através do Contact / Support.

9. Cookies

O World Cigar Locator utiliza cookies essenciais necessários para o funcionamento do site e análises limitadas para entender padrões de uso e melhorar o desempenho.

Você pode controlar os cookies através das configurações do seu navegador.

10. Segurança

Utilizamos infraestrutura moderna em nuvem e serviços de banco de dados para proteger dados pessoais contra acesso não autorizado, alteração ou destruição.

O acesso aos sistemas operacionais é restrito e monitorado. No entanto, nenhum sistema pode garantir segurança absoluta.

11. Alterações nesta Política

Podemos atualizar esta Política de Privacidade periodicamente. O uso contínuo do site constitui aceitação de quaisquer atualizações.
